# 变更记录

## 1.10.0

### 修复

- dry-run 构造脱敏报文时不再刷新 OAuth、联网或写凭据；真实请求才检查令牌有效期。
- 写请求网络结果不明时不自动重试，传输结果区分 `failed` 与 `unknown`。
- env-only 凭据在账户列表可见；环境覆盖不得写回文件；文件名决定持久化 alias。
- 损坏凭据、异常响应和错误 JSON 结构返回可操作的错误，不再静默当作无账户或裸崩溃。
- OAuth 手工收码输出 `auth_code` 与下一步命令；自动换令牌返回脱敏凭据；失败正确返回非零。
- OAuth 使用跨进程一次性 nonce，会话不含 SecretKey/token/authCode，重放与旧链接拒绝。
- 修复 KR 索引方法名；校验响应结构；统计标明单次响应、limit 范围与简单平均口径。
- 写审计按 request_id 记录 attempted 与 succeeded/failed/unknown；透传使用同一生命周期。
- 复制预览与执行共用模板，预检批量与产品线；部分失败保留已创建 ID 和失败步骤。

### 行为变化

- 旧 OAuth 授权链接失效，必须重新运行 `auth link`。
- 写审批 digest 加入 product_line，旧 digest 需要重新预览。
- 跨账户复制目标为全部新物料默认暂停；四层暂停字段没有官方协议或测试证据时，
  预览标为不可执行，真实执行在发送任何请求前拒绝。该能力仍为实验能力。
- SecretKey 用于刷新并保存在本地权限受控的凭据 JSON；不随技能分发、不公开回显。
- Python 3.9+ 直接运行与 uv 执行均可，Windows fallback 使用 `py -3`。

### 验证边界

- 离线测试不访问百度、不执行真实写操作。
- 百度自定义 state 回传、KR 分页完整性、四层可写暂停字段和真实创建响应仍需官方协议或
  用户提供的脱敏证据；模拟 fixture 不作为生产兼容性证明。
