# 图片 → 投流关键词集合 SOP（Agent 执行用）

这份 SOP 规定：用户给一张或多张商品图，你如何产出**可直接导入百度推广后台**的关键词分组。

**一条铁律贯穿全程：所有关键词必须来自 `KRService.getKRByQuery` 的真实返回，禁止凭经验编词。**
编出来的词在后台可能零展现，用户花了钱才发现，比不给方案更糟。

---

## 触发条件

用户出现以下任意表达时，走本 SOP：

- 给了商品图（1 张或多张），要求拓词、做关键词、做投放分组
- 「这几张图能投什么词」「按图给我出关键词」「帮我把这些产品做成投放词包」
- 已有产品名但要求「按卖点方向分组」「出可导入后台的词表」

不需要走本 SOP 的情况：只问某个词的价格、只查账户数据、只做策略讨论不产出词表。

**走本 SOP 时，不套用人设里的四步策略流程**（诊断现状 → 策略匹配 → 执行清单 → 合规提示）。
那条流程是给纯策略咨询用的，套在词包请求上会先问一堆行业/预算问题，把用户问跑。
本 SOP 只做一件事：把图变成能导入后台的词表。

---

## 流程总览

```
图片 ──①──> 产品档案 ──②──> 种子词 ──③──> 拓词 ──④──> 筛词
                                                          │
                         交付物 <──⑦── 否词 <──⑥── 优先级 <──⑤── 分组
```

**一张图 = 一个产品 = 一批**。多张图就独立跑 N 遍，最后合并交付。
不要在一批里混两个产品，否则分组会串。

---

## 第 1 步：读图，产出产品档案

用视图能力逐张读图，从图上文字和画面提取六项。**只提取图上确实存在的信息，不要补。**

| 字段 | 从哪看 | 用途 |
|---|---|---|
| 产品名 | 图上主标题 / 包装主标 | 组 1 命名、最终产品名 |
| 品类词根 | 产品名里去掉修饰词剩下的核心词 | **筛词的锚点，最关键** |
| 核心卖点 | 图上最大的 3–4 组字 | 组 2 方向、来源卖点词 |
| 规格 / 成分 | 净含量、有效成分、数量 | 判断是否属于特殊类目（农药、兽药、化妆品备案） |
| 使用场景 | 图上的场景画面（室内、花盆、宠物床） | 组 4 方向、环境类种子词 |
| 目标人群 | 图中人物或宠物类型 | 组 4 人群切分 |

产出格式（内部用，不必给用户看全部）：

```
产品档案 #1
  产品名：月季玫瑰专用肥
  品类词根：肥
  核心卖点：花大色艳 / 花期持久 / 缓释长久 / 家庭园艺
  规格成分：未标注
  使用场景：盆栽、花园
  目标人群：家庭养花人群
```

**品类词根是最重要的一项。** 它是后面筛词的锚：不含词根、也不是明确同义词的，一律不进词表。

图上信息不足时（比如只有产品图没有文案），按品类常识补一个**待确认**标记，并在交付时告诉用户「卖点是从品类推断的，与实物不符请指正」。

## 第 2 步：生成种子词（决定成败的一步）

### 实测规律（来自 77 个种子词的真实返回量）

这不是经验之谈，是跑过的数据：

| 种子词形态 | 例子 | 典型返回量 |
|---|---|---|
| **品类词根本身（最短）** | 月季、花肥、缓释肥、化毛膏、宠物驱虫、跳蚤药 | **300（满量）** |
| 物种/人群 + 品类 | 狗狗跳蚤、猫跳蚤、猫咪体外驱虫、幼猫化毛 | **300** |
| 场景 + 品类 | 宠物环境驱虫、沙发除螨 | 175–300 |
| 属性 + 品类 | 月季专用肥、花卉肥料、缓释肥 | 276–300 |
| 复合属性词 | 花卉缓释肥料、长效肥、开花肥、玫瑰肥 | 63–142 |
| **产品全名 / 形态限定** | 体外驱虫喷雾、驱虫喷雾、除蚤喷雾 | **50–179（掉量）** |
| 口语长句 | 鸡腿软站不起来、鸭子腿软站不起来 | 22–30 |
| 品牌词 / 自造词 | 软腿宝、牧德旺、鸡软腿宝、家禽腿软 | **0–1（无效）** |
| 专业术语 | 鸡滑腱症 | 2 |
| 过度限定 | 鸡瘫痪急救、鸡软腿急救 | **0–1** |

三条结论：

1. **越短越宽。** 单词型品类词根稳定打满 300 条；每加一层限定，返回量掉一个数量级。
2. **产品全名不是好种子词。** 「体外驱虫喷雾」只回 50 条，而「宠物驱虫」回 300 条。用户搜的不是你的产品名。
3. **品牌词在自己店里通常零搜索量。** 除非用户明确要求投品牌词，否则不跑。

### 每个产品跑 8–12 个种子词

分四层，每层都有明确目的：

| 层 | 数量 | 怎么取 | 例子（月季肥） |
|---|---|---|---|
| **L1 品类词根** | 1–2 | 产品名的核心词，**不加减任何限定** | 月季、花肥 |
| **L2 物种/人群切分** | 2–3 | 谁用它；有多个物种就分别跑，搜索习惯不同 | 盆栽月季、玫瑰种植 |
| **L3 卖点转词** | 2–4 | 每个核心卖点取关键词 + 品类词根 | 促花肥、缓释肥、开花肥 |
| **L4 场景转词** | 2–3 | 使用场景 / 痛点场景 + 品类 | 宠物环境驱虫、沙发除螨 |

L1 保证覆盖量，L2 切分人群的习惯用语，L3 和 L4 挖差异化长尾。**四层缺一层，词包就会偏。**

### 卖点转种子词的映射

| 卖点类型 | 种子词写法 | 已验证的例子 |
|---|---|---|
| 效果型（花大、开花多） | 效果动词 + 品类 | 促花肥、开花肥 |
| 工艺型（缓释、长效） | 工艺形容词 + 品类 | 缓释肥、长效肥、花卉缓释肥料 |
| 痛点型（吐毛球、跳蚤） | 痛点词本身或痛点 + 品类 | 猫吐毛球、猫毛球、跳蚤药 |
| 场景型（环境可用、床边） | 场景 + 品类 | 宠物环境驱虫、沙发除螨 |
| 通用型（猫狗通用） | **不要用「通用」当种子词**（`犬猫通用` 只回 5 条），改成分别跑猫、狗 | 猫掉毛、狗狗化毛 |

### 不要跑这些

- 产品全名 / SKU 名（掉量）
- 品牌词（自家零搜索量）
- 专业术语、学术名词（用户不这么搜）
- 「急救」「特效」「根治」这类营销形容词（几乎必归零）
- 「XX 怎么办」以外的口语长句（`鸡瘫痪站不起来` 只回 1 条）

## 第 3 步：批量拓词

先自检账户（没账户就按 `auth-sop.md` 引导，不要硬跑）：

```bash
python3 scripts/bmctl.py accounts list
```

一次跑完一个产品的全部种子词，去重合并：

```bash
python3 scripts/bmctl.py kr multi --seeds "月季,花肥,盆栽月季,促花肥,缓释肥" --format json
```

**必须看每个种子词的 `returned` 和 `new`：**

| 现象 | 含义 | 动作 |
|---|---|---|
| `returned: 300`，`new` 高 | 有效宽口径 | 保留 |
| `returned: 300`，`new` 很低（<30） | 词群已被别的种子词覆盖 | 记住它，下批不用再跑同类 |
| `returned` < 50 | 种子词太窄 | **换更宽的词重跑**，别将就 |
| `returned` ≤ 2 | 无效词 | 丢弃，不要在方案里提这个词群 |

想单独看某个种子词的量级和均价：

```bash
python3 scripts/bmctl.py kr expand --seed "月季" --summary
```

单个种子词最多回 300 条，这是接口上限，不是被截断。想要更多只能加种子词。

## 第 4 步：筛词（人工语义判断，不能脚本化）

拓回来的是**1000–3000 词的原始池**，里面八成是噪声。按下面的规则过两遍。

### 保留：必须同时满足

1. **含品类词根，或是明确的同义/近义表达**
2. **带购买或使用意图信号** —— 出现下列任一：
   - 怎么用 / 怎么施 / 用多少 / 什么时候用
   - 哪个好 / 什么牌子 / 哪种 / 推荐
   - 有用吗 / 效果怎么样 / 管用吗 / 多久见效
   - 能治吗 / 怎么办（症状求解场景）
   - 多少钱 / 价格 / 在哪买
3. **不是纯信息型**（见下）

### 剔除：按类归，一类不留

| 类型 | 特征 | 例子 |
|---|---|---|
| 信息科普 | 是什么 / 有什么区别 / 原理 / 图片 / 拼音 / 视频 | 缓释肥是什么肥、月季和玫瑰的区别 |
| 操作方法 | 怎么种 / 怎么养 / 怎么剪 / 什么时候种 | 月季怎么修剪、玫瑰种植方法 |
| 跨品类 | 词根相同但指向别的品类 | 玉米缓释肥、水稻专用肥、蓝莓土 |
| 器械工具 | 机器、器具、耗材 | 除螨仪、吸尘器、除螨包、花盆 |
| 替代形态 | 同功效但不同剂型（除非策略要截流） | 滴剂、项圈、化毛膏（对化毛片而言） |
| 人用 | 人用同类品 | 人用驱虫、腿软吃什么药（人） |
| 竞品品牌 | 其他品牌名 | 花多多、奥绿 |
| 营销自造 | 你编的词 | — |

**「跨品类」和「器械工具」漏掉最烧钱**：它们搜索量往往不低，但点进来的人根本不买。这两类必须逐词检查。

### 筛完的量级参照

昨天三个产品的实测结果，可以作为「筛得对不对」的标尺：

| 指标 | 健康区间 |
|---|---|
| 单个产品筛出词数 | **80–130 词** |
| 每组词数 | **20–40 词** |
| 筛出率（筛出 ÷ 原始池） | 3%–8% |

- 远超 130 词：大概率筛松了，回去查跨品类词
- 不足 80 词：大概率种子词不够宽，回第 2 步补 L1/L2
- 某组不足 15 词：这个方向在该品类下没有真实需求，**如实说明，不要硬凑**

## 第 5 步：分四组（每组一个投放方向）

固定四方向模板，顺序也固定：

| 组 | 方向 | 选词标准 | 对应卖点 |
|---|---|---|---|
| **组 1** | 精准产品 | 产品名 + 品类词根，用户已经在找这个产品 | — |
| **组 2** | 核心功效 | 主打卖点的效果问句 | 卖点第 1 条 |
| **组 3** | 痛点场景 | 用户遇到的具体问题、症状求解 | 卖点第 3–4 条 |
| **组 4** | 人群/场景扩展 | 差异化人群，或第二使用场景 | 卖点最后一条 + 使用场景 |

命名格式固定：

```
组1｜精准产品·月季玫瑰专用肥
组2｜促花效果·开花多/花苞多/花大色艳
组3｜缓释长效·一次施肥管很久
组4｜家庭园艺·阳台盆栽/新手好上手
```

`组N｜` 后面跟「方向短语·具体定义」，用 `·` 分隔。**四组命名风格要一致**，不要一组写功效、一组写人群。

组 4 的价值在于**别人没有的场景**。昨天「宠物环境驱虫」这组只有 484 搜索，但它是该产品唯一能喷床铺沙发的差异化点 —— 量小仍要保留，用来低价占位。

---

## 第 6 步：排优先级（P1–P4）

不是按搜索量从大到小排，而是按 **搜索量 × 购买意图纯度** 排：

| 优先级 | 判断标准 | 典型归属 |
|---|---|---|
| **P1** | 意图最纯，搜的人就是来买这个的。量可以不大 | 组 1 精准产品 |
| **P2** | 量大且意图明确（找解决方案） | 组 3 痛点场景，或组 2 |
| **P3** | 量最大但偏科普/焦虑，未必当场下单 | 组 2 或组 3 中偏问「正常吗/怎么回事」的那组 |
| **P4** | 量小但差异化强，价值在占位和拉新场景 | 组 4 |

**理由必须带数字，且说清判断依据。** 昨天合格的写法：

```
P1 组1｜精准产品·月季玫瑰专用肥
    原因：34 词直接搜产品名，购买意图最强，词少但成交确定性最高，必须独占；搜索 533、均价 1.24。

P3 组2｜毛球症·吐毛球/毛球堵塞
    原因：2796 搜索量最大，但约半数在问「正常吗/是好事吗」，属焦虑科普型，未必当场下单；
          适合低价跑量 + 科普落地页二次转化，故排第三。
```

不合格的写法：「组 1 最重要，因为意图精准。」——没有数字，没有可验证的依据。

搜索量和均价从 `kr.summarize` 或 `kr expand --summary` 拿，不要自己估。

---

## 第 7 步：定否词

否词是从**拓词结果里反推**的，不是凭空想。方法：翻原始池，找出搜索量不低但不属于本品类的词群，按类归并。

输出格式固定，分号前是词，括号里是归类理由：

```
否词提示：种植/怎么种/苗/老桩/品种/修剪/冬剪/图片/拼音/玉米/水稻/蓝莓/多肉/兰花/花盆/土/花多多（不同品类或纯信息型）
```

三类必写：

1. **跨品类词** —— 词根相同但卖的货不对
2. **器械/替代形态** —— 搜索者要的是别的解决方案
3. **纯信息型** —— 不产生购买

## 产出物格式（严格对齐，可直接导入后台）

每批产出三件：

### 1. 分产品纯文本（可整段粘贴进后台）

文件名：`关键词分组_<序号>_<产品名>.txt`

```
==================================================================
产品1｜月季玫瑰专用肥（花大色艳·花期持久·缓释长久·家庭园艺）
共 109 个关键词 · 4 组
==================================================================

【组1｜精准产品·月季玫瑰专用肥】34 词
月季专用肥
月季玫瑰专用肥
...

------------------------------------------------------------------
【投放优先级】
P1 组1｜精准产品·月季玫瑰专用肥
    原因：<带数字的判断>

P2 组2｜...

否词提示：<词/词/词>（<归类>）
```

规则：
- 分隔线 `=` 66 个，组间分隔 `-` 66 个
- 产品标题行格式 `产品N｜产品名（卖点1·卖点2·卖点3·场景）`
- 每组标题 `【组N｜方向·定义】N 词`
- **关键词一行一个，不加序号、不加引号、不排序注释** —— 这样才能直接导入
- 优先级、否词放在最后一个组的后面，不要放开头

### 2. 合并纯文本

文件名：`关键词投流分组_<N>产品_纯文本.txt`

内容同上，产品之间空两行，标题行末尾多一句 `· 数据源：百度关键词规划师 KRService.getKRByQuery`。

### 3. 数据附表 CSV

文件名：`关键词投流分组_<N>产品_数据附表.csv`

```
产品,分组,序号,关键词,日均搜索量,展现,点击,竞争度,推荐出价
产品1,组1｜精准产品·月季玫瑰专用肥,1,月季专用肥,11,39,8,1,1.05
```

- UTF-8 **带 BOM**（Excel 打开不乱码）
- 序号在组内从 1 开始
- 数值字段直接用接口原值，不要四舍五入

### 4. 对话里的摘要（Markdown）

文件之外，向用户展示一张总表：

| 产品 | 词数 | 组数 | 搜索量合计 | 均价 | 首推组 |
|---|---|---|---|---|---|
| 月季玫瑰专用肥 | 109 | 4 | — | 1.20 | 组1 精准产品 |

## 内置提示词（供用户选择）

用户不知道该提什么要求时，给出这几条让他挑：

| 场景 | 提示词 |
|---|---|
| **标准四组**（默认） | 按图给每个产品拓词，分成精准产品、核心功效、痛点场景、人群扩展四组，排好投放优先级并给否词 |
| **预算收紧** | 只做精准产品组和高意图痛点组，每组控制在 20 词以内，按转化可能性排序 |
| **最大化覆盖** | 每个产品拓到 150 词以上，四组都要满，优先保搜索量大的方向 |
| **单品深挖** | 只做这一张图，把这个产品挖到 200 词，按使用场景再细分 |
| **对比选品** | 这几个产品各出方案，然后横向比较搜索总量、均价、竞争度，告诉我先投哪个 |

## 交付前自检

逐条过，有一条不过就不要交付：

- [ ] 每个词都能在 KR 原始返回里找到（抽查 10 个，含搜索量最大的和最奇怪的）
- [ ] 词数在 80–130 / 产品，每组 20–40
- [ ] 四组命名风格一致，都是「方向·定义」
- [ ] 优先级理由**每一条都带数字**
- [ ] 否词三类齐全（跨品类 / 器械替代 / 纯信息）
- [ ] txt 里关键词一行一个，无序号无引号（能直接导入）
- [ ] CSV 带 BOM，序号组内连续
- [ ] 告诉用户数据来自哪个账户、哪个接口、什么时候取的

## 出词之后（可选）：直接写进账户

词表确认后，可以用 `write word-add` 直接落到某个单元，省掉手工导入。三条前置：

1. **先确认落到哪个单元**（`--adgroup-id`）。用户说不清就先只给词表，不要猜单元。
2. **出价与匹配模式必须由用户拍板**。词包里的 `rec_bid` 只是基准值，不能直接当出价写进去。
3. **先 dry-run 一次**，把报文里的词数、单价、匹配模式、目标单元贴给用户，确认后再加 `--execute`。

单次上限 200 词，超过要分批，并明确告诉用户分几批、每批多少。

## 常见失败

| 现象 | 根因 | 修法 |
|---|---|---|
| 词数只有几十个 | 种子词太窄，或只跑了产品全名 | 补 L1 品类词根，回第 2 步 |
| 词多但都很冷（搜索量 ≤10） | 只筛了语义没筛量级，长尾过重 | 按搜索量降序复核，把 ≤10 的压到最后或剔除 |
| 成品里混进跨品类词 | 筛词只看了词根没看语义 | 逐词过一遍剔除表 |
| 四组词量严重不均（一组 5 词一组 80 词） | 卖点与真实搜索需求不匹配 | 如实说明哪组需求薄弱，不要硬凑 |
| 用户说「这些词我不投」 | 卖点理解偏了 | 回到第 1 步重新读图，确认品类词根 |
| 账户报 89406 | 权限域未开通，不是令牌失效 | 说明情况，引导补权限，不要重试 |

**拿不到数据时**：如实告诉用户「本机未接入百度营销账户，无法取真实搜索量」，给出不含数字的方案框架并标注哪些待验证。**绝不能把估算值写得像实测值。**
